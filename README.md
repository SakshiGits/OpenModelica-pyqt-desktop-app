# Two Connected Tanks Simulation App

## Overview
This project is a desktop application built using **Python (PyQt)** integrated with **OpenModelica** to simulate and visualize the behavior of two interconnected tanks system. It allows users to run simulations, adjust parameters, and observe system dynamics in real time.

---

## Features
- Graphical User Interface built with PyQt
- Integration with OpenModelica simulation engine
- Simulation of two connected tank dynamics
- Configurable simulation parameters (start time, stop time)
- Real-time simulation log output 
- Error handling for invalid simulation inputs

---

## Project Structure

## Project Structure

OPENMODELICA-PYQT-DESKTOP-APP/

- `main.py`  
  - Entry point of the application  
  - Initializes the PyQt application  
  - Launches the main GUI window  

- `app/`  
  - Core application module  
  - Contains UI logic and simulation control  

  - `ui.py`  
    - Builds and manages the PyQt user interface  
    - Handles buttons, input fields, and layout design  
    - Manages user interactions  

  - `runner.py`  
    - Executes OpenModelica simulations  
    - Passes user inputs (start time, stop time, parameters)  
    - Handles simulation runtime and output retrieval  

- `TwoConnectedTanks/`  
  - OpenModelica compiled simulation directory  
  - Contains executable and runtime dependencies  

  - `TwoConnectedTanks.exe`  
    - Compiled simulation executable generated by OpenModelica  
    - Runs the simulation model  

  - `*.dll files`  
    - Required dynamic link libraries  
    - Provide backend support for simulation execution  

- `README.md`  
  - Project documentation

## How to Run

### Step 1: Clone the Repository
```bash
git clone <repo-link>
```
### Step 2: Navigate to the Project Directory
```
cd OPENMODELICA-PYQT-DESKTOP-APP
```
### Step 3: Run the application
```
python main.py
```

### Step 4: Configure Inputs for Simulation

- **Executable Path** : Browse to the project folder -> TwoConnectedTanks folder -> select the executable application file.
- **Start Time** :  Make it between (0-3) for testing purposes.
- **Stop Time**  : Make it between (1-4) for testing purposes.
